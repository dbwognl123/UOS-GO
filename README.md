**UOS-GO**는 서울시립대학교 캠퍼스를 배경으로 한 2D 도트 스타일 대학생활 시뮬레이션 게임입니다.  
플레이어는 16주 동안 학교생활을 하며 수업, 공부, 아르바이트, NPC 상호작용 등을 통해 능력치를 성장시키고, 최종적으로 다양한 엔딩을 수집하는 것을 목표로 합니다.

게임은 단순히 능력치를 올리는 방식이 아니라, 체력과 시간, 돈을 관리하면서 어떤 선택을 할지 고민하게 만드는 것을 핵심 재미로 삼고 있습니다.

---

## 게임 컨셉

플레이어는 한 학기 동안 대학생활을 진행합니다.  
매일 아침 집에서 하루를 시작하고, 학교에 가거나 쉬는 선택을 할 수 있습니다.  
학교에서는 수업을 듣거나 NPC를 만나고, 저녁에는 공부, 아르바이트, 휴식을 선택할 수 있습니다.

16주가 끝나면 플레이어의 최종 능력치와 선택에 따라 엔딩이 결정됩니다.

---

## 주요 특징

### 1. 16주차 기반 진행 구조

게임은 총 16주 동안 진행됩니다.

- 1주차부터 16주차까지 하루 단위로 진행
- 매일 아침, 학교, 저녁 씬을 순서대로 이동
- 16주차 종료 후 엔딩 씬으로 이동
- 엔딩은 조건에 따라 다르게 결정
- 이미 본 엔딩은 수집품 화면에서 확인 가능

---

### 2. 능력치 시스템

플레이어는 여러 능력치를 가지고 있으며, 선택에 따라 능력치가 변화합니다.

| 능력치 | 설명 |
|---|---|
| 지능 | 수업 성공률, 성적, 일부 NPC 이벤트에 영향을 줌 |
| 체력 | 학교 활동과 미니게임 진행에 영향을 줌 |
| 돈 | 아르바이트, 선택지, 상점 이용에 사용 |
| 학교생활력 | 친구, 선배 등 학교 관련 이벤트에 영향을 줌 |
| 친화력 | NPC와의 관계 및 성공률에 영향을 줌 |
| 행복도 | 엔딩 조건 및 일부 선택지에 영향을 줌 |

체력은 현재 체력과 최대 체력 개념을 구분합니다.  
학교에서는 시간이 지날수록 현재 체력이 감소하며, 공부나 아르바이트는 최대 체력에 영향을 줄 수 있습니다.

---

### 3. 씬 구조

게임은 여러 씬으로 구성됩니다.

| 씬 이름 | 설명 |
|---|---|
| MainScene | 게임 시작, 상점, 수집품으로 이동하는 메인 화면 |
| MorningScene | 하루를 시작하는 집 내부 씬 |
| SchoolScene | 학교에서 수업, NPC, 이동을 진행하는 씬 |
| EveningScene | 저녁에 공부, 아르바이트, 취침을 선택하는 씬 |
| ShopScene | 재화를 사용해 아이템을 구매하는 씬 |
| CollectionScene | 수집한 엔딩을 확인하는 씬 |
| EndingScene | 최종 결과와 엔딩을 확인하는 씬 |

## 게임 흐름

```text
MainScene
   ↓
MorningScene
   ↓
학교에 간다 / 쉰다 선택
   ↓
SchoolScene 또는 EveningScene
   ↓
EveningScene
   ↓
잠자기
   ↓
다음 주차 MorningScene
   ↓
16주차 종료
   ↓
EndingScene
